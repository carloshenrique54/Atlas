## ◈ Visão Geral

O **Atlas** é um serviço web de gestão corporativa desenvolvido pela **Atlas Dev**, com o objetivo de reduzir o custo operacional e a complexidade de gestão para empresas e profissionais em início de trajetória.

Pensado para quem não quer depender de sistemas complexos ou caros, o Atlas entrega uma interface dinâmica, intuitiva e poderosa para o gerenciamento do dia a dia corporativo — desde tarefas e equipes até relatórios e controle de funcionários.

---

## ✦ Funcionalidades

| ◆ Módulo | › Descrição |
|----------|-------------|
| `[ Dashboard Corporativo ]` | Visão centralizada e completa das operações da empresa |
| `[ Gestão de Equipes ]` | Organização de times, funções e colaboradores |
| `[ Gerenciamento de Tarefas ]` | Criação, atribuição e acompanhamento de tarefas |
| `[ Controle de Funcionários ]` | Cadastro e manipulação de dados de colaboradores |
| `[ Relatórios Automáticos ]` | Geração de relatórios com visualizações claras |
| `[ Interface Responsiva ]` | Design moderno e adaptado a qualquer dispositivo |

## ▸ Como Executar Localmente

**Pré-requisitos:** Node.js `v18+` e npm instalados.

```bash
# › Clone o repositório
git clone https://github.com/carloshenrique54/Atlas.git

# › Acesse o diretório
cd Atlas

# › Instale as dependências
npm install

# › Inicie o servidor de desenvolvimento
npm start
```

O projeto estará disponível em `http://localhost:3000`

```bash
# › Build para produção
npm run build

# › Executar testes
npm test
```
